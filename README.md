# suhibug.github.io

Personal portfolio of Suhitha Lakkunda Rathnakara: the projects I've built, my video work, and my experience, all on one page.

**Live at https://suhibug.github.io/**

## What's on the site

- **Featured projects**: Trail Prep (my free hike planner), getting ASU found in AI search, AI thumbnails for YouTube, the Sun Devil Hotline podcast, and more
- **Strategy and research work**: audience personas and a full-funnel plan, a competitive analysis of 10 universities, a Markstrat B2B simulation, Ivy (an EdTech venture), the digital music industry, SafeAlert's go-to-market plan
- **Media and tech experiments**: 360° video, smell in digital media, telepresence avatars for live performance, teaching a computer to see app screens, air instruments
- **Video work**, **experience**, and a **contact** section

## What each file does

| File | What it does |
|---|---|
| `index.html` | The whole site: every section and project lives on this one page |
| `style.css` | How it looks (layout, colors, fonts, phone layout) |
| `analytics.js` | Anonymous visit counts (Google Analytics 4 and GoatCounter). Setup steps are in [personal-analytics](https://github.com/suhibug/personal-analytics) |
| `favicon.svg` | The small icon in the browser tab |
| `og.png` | The preview picture that shows when the link is shared (LinkedIn, iMessage, etc.) |
| `sitemap.xml` | Helps Google find every page |

## How to update it

1. Edit `index.html` (and `style.css` for looks).
2. Open GitHub Desktop, write a short summary of the change, click **Commit to main**, then **Push origin**.
3. GitHub Pages publishes it to https://suhibug.github.io/ in about a minute.

Plain HTML and CSS, with no build step and no framework.
